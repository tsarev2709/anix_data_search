# TgNinja: словарь для радара Anix

Настраивайте слежение за **новыми сообщениями** в рабочих чатах, а не за всеми каналами подряд. Сначала добавьте чаты маркетологов, продюсеров, специалистов по обучению, охране труда и фармацевтических компаний, где разрешены запросы подрядчиков. Одни слова вроде «видео» дадут много шума; сочетайте намерение и услугу, когда TgNinja поддерживает условия.

## Аккаунт 1 — маркетинг и видеопродакшн

Намерение: `ищем`, `ищу`, `нужен`, `нужна`, `посоветуйте`, `порекомендуйте`, `кто сделает`, `где заказать`, `тендер`, `закупка`, `подрядчик`, `бриф`, `смета`, `КП`.

Услуга: `видеопродакшн`, `рекламный ролик`, `продуктовое видео`, `имиджевый ролик`, `проморолик`, `анимационный ролик`, `2D анимация`, `3D анимация`, `моушн дизайн`, `объясняющее видео`, `видеокейс`, `корпоративный фильм`, `ролик для выставки`, `ролик для конференции`, `презентационное видео`.

Примеры фраз: `ищем студию для ролика`, `посоветуйте видеопродакшн`, `нужно сделать анимацию продукта`, `тендер на видеопроизводство`, `кто снимет видеокейс`, `ищем подрядчика на проморолик`.

## Аккаунт 2 — фарма, охрана труда и обучение

Намерение: те же слова плюс `нужно объяснить`, `нужно обучить`, `планируем запуск`, `разрабатываем программу`, `ищем решение`.

Услуга: `видео по охране труда`, `видеоинструктаж`, `ролик по технике безопасности`, `промышленная безопасность`, `обучающее видео`, `видеокурс`, `онбординг сотрудников`, `видео для HR`, `внутренние коммуникации`, `медицинская анимация`, `фармацевтический ролик`, `механизм действия препарата`, `видео для пациентов`, `видео для врачей`, `видео для клиники`.

Примеры фраз: `ищем подрядчика на видеоинструктаж`, `нужно снять ролик по охране труда`, `посоветуйте студию медицинской анимации`, `заказать видео для обучения сотрудников`, `тендер на фармацевтический ролик`.

Проверьте на реальных находках каждую группу фраз. Отключайте источники с постоянной саморекламой и вакансиями. Вебхук дополнительно отсечёт вакансии, бесплатные материалы и сообщения без явного запроса на видеоматериал. Словарь TgNinja задаётся в самом сервисе; это приложение не может изменить его настройки без отдельной интеграции.
